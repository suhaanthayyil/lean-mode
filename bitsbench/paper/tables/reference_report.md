# BITS-Bench report

## Leaderboard (equal weight per configuration)

- `predict`: test accuracy above the prior baseline as a fraction of the greedy-EIG Bayes reference's, averaged over checkpoints. `p_gather + p_infer` = accuracy below that reference.
- `discover`: exact-identification rate of the final RULE as a fraction of the reference's MAP mass. `d_gather + d_infer` = identification below that reference.
- `bits_score` = mean of predict and discover; `info_eff` = bits gathered / reference bits; `design_eff` = (bits - random bits) / (reference bits - random bits).
- `eig_ratio`: mean expected information gain of the agent's experiments relative to the best available experiment at that step; `determined`: fraction of experiments whose outcome was already entailed by earlier results (noise-free domains). Both are for the active condition only.
